# Package index

## Charte graphique

- [`theme_DGT()`](https://thomasfaria.github.io/dgtcharts/reference/theme_DGT.md)
  : Thème ggplot2 à la charte DG Trésor
- [`DGT_col`](https://thomasfaria.github.io/dgtcharts/reference/DGT_col.md)
  : Palette de couleurs DG Trésor (inspirée du DSFR)

## Graphiques statiques

- [`plot_lines()`](https://thomasfaria.github.io/dgtcharts/reference/plot_lines.md)
  : Famille 1 : Graphique lignes
- [`plot_bar_line()`](https://thomasfaria.github.io/dgtcharts/reference/plot_bar_line.md)
  : Famille 2 : Graphique barres + ligne avec double axe
- [`plot_lines_area()`](https://thomasfaria.github.io/dgtcharts/reference/plot_lines_area.md)
  : Famille 3 : Plusieurs lignes + aire pour le total
- [`plot_lines_facet()`](https://thomasfaria.github.io/dgtcharts/reference/plot_lines_facet.md)
  : Famille 6 : Lignes en facets avec highlight (une série mise en
  couleur par facet, autres en grisé)
- [`plot_contrib()`](https://thomasfaria.github.io/dgtcharts/reference/plot_contrib.md)
  : Famille 7 : Barres empilées (contributions) + ligne (variation
  annuelle totale)

## Graphiques interactifs (HTML)

- [`plot_bar_line_interactive()`](https://thomasfaria.github.io/dgtcharts/reference/plot_bar_line_interactive.md)
  : Famille 2 : Graphique barres + ligne avec double axe (version
  interactive)
- [`plot_contrib_interactive()`](https://thomasfaria.github.io/dgtcharts/reference/plot_contrib_interactive.md)
  : Famille 6 : Barres empilées (contributions) + ligne (variation
  annuelle totale) — version interactive
- [`plot_lines_area_interactive()`](https://thomasfaria.github.io/dgtcharts/reference/plot_lines_area_interactive.md)
  : Famille 3 : Plusieurs lignes + aire pour le total (version
  interactive)
- [`plot_lines_facet_interactive()`](https://thomasfaria.github.io/dgtcharts/reference/plot_lines_facet_interactive.md)
  : Famille 5 : petits multiples (une série par facette, les autres en
  fond gris) — version interactive
- [`plot_lines_interactive()`](https://thomasfaria.github.io/dgtcharts/reference/plot_lines_interactive.md)
  : Famille 1 : Graphique lignes (version interactive)

  graphique

## Utilitaires pour les graphiques

- [`create_tooltip()`](https://thomasfaria.github.io/dgtcharts/reference/create_tooltip.md)
  : Fonction helper pour créer des tooltips formatés
- [`create_series_map()`](https://thomasfaria.github.io/dgtcharts/reference/create_series_map.md)
  : Cree un tibble de mapping series/labels/couleurs
- [`add_caption()`](https://thomasfaria.github.io/dgtcharts/reference/add_caption.md)
  : Ajouter une caption avec sources et dernier point
- [`calculate_scale_factor()`](https://thomasfaria.github.io/dgtcharts/reference/calculate_scale_factor.md)
  : Calcule le facteur d'echelle pour les graphiques a double axe
- [`format_date_fr()`](https://thomasfaria.github.io/dgtcharts/reference/format_date_fr.md)
  : Formate une date en français
- [`get_latest_date()`](https://thomasfaria.github.io/dgtcharts/reference/get_latest_date.md)
  : Formate la date la plus récente dans un jeu de données
