# Palette de couleurs DG Trésor (inspirée du DSFR)

Vecteur nommé de 18 couleurs. Utiliser les noms plutôt que les positions
(`DGT_col["bleu_france"]`,
`DGT_col[c("bleu_france", "rouge_marianne")]`). Ne jamais coder une
couleur en dur dans un graphique.

## Usage

``` r
DGT_col
```

## Format

Vecteur nommé de codes hexadécimaux.

## Examples

``` r
DGT_col[c("bleu_france", "rouge_marianne")]
#>    bleu_france rouge_marianne 
#>      "#000091"      "#E1000F" 
```
