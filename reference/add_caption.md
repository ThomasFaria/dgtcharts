# Ajouter une caption avec sources et dernier point

Ajouter une caption avec sources et dernier point

## Usage

``` r
add_caption(sources = "", last_point = "")
```

## Arguments

- sources:

  character, source des données (vide par défaut)

- last_point:

  character, dernier point des données (vide par défaut)

## Value

ggplot2 labs object ou NULL si aucune caption n'est nécessaire
